# Patient Admission Management App – Frontend

Responsive React.js web app for hospital staff to admit, search, filter, update, discharge, and delete patient records.

## Live Links
- **Live App:** `https://patient-admission-management-frontend.onrender.com/`
- **Backend API:** `https://patient-admission-management-backend-ash8.onrender.com/api/patients`
- **Backend Repo:** `https://github.com/Abhi1289-prog/Patient_Admission_Management_Backend.git`

## Tech Stack
- **Frontend:** React.js (Vite), CSS3 (Responsive for mobile, tablet, and desktop)
- **Backend:** Java 21, Spring Boot 3, Spring Data JPA, Bean Validation
- **Database:** PostgreSQL

## Features
- Admit new patients with client-side and server-side validation
- View all patients with Admitted / Discharged summary counts
- Search patients by name and filter by Ward, Department, and Doctor
- Edit patient details, mark patients as Discharged, and delete with confirmation
